# Подарок имениннику

Статическая страница для GitHub Pages: именинник нажимает на подарок, после чего открывается и запускается видео поздравления.

## Добавить видео

Положите файл поздравления в эту же папку и назовите его `video.mp4`. Используйте обычный MP4 (H.264/AAC), чтобы он открывался на телефонах и компьютерах. Большой видеофайл можно хранить на внешнем видеохостинге и заменить `src="video.mp4"` в `index.html` на прямую ссылку на MP4.

## Опубликовать на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в него `index.html` и `video.mp4`.
3. Откройте **Settings → Pages**.
4. В разделе сборки выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. После публикации откройте ссылку, которую покажет GitHub Pages, и проверьте подарок на телефоне.

Видео включается после нажатия на подарок. Это нужно, потому что браузеры обычно блокируют звук и автоматическое воспроизведение до первого действия зрителя.
